# Laboratorium 4 - Aplikacja Backendowa z Express.js

## Cel projektu
Praktyczne zastosowanie frameworka Express 5.x do budowy warstwy usług aplikacji internetowej zgodnie z architekturą warstwową.

## Zrealizowane funkcjonalności
* **Zadanie 4.1:** Konfiguracja serwera w Express.js oraz organizacja projektu.
* **Zadanie 4.2:** Obsługa routingu i parametrów żądań (`req.params`, `req.query`).
* **Zadanie 4.3:** Własne middleware (logger) oraz udostępnianie plików statycznych.
* **Zadanie 4.4:** Zbudowane REST API do zarządzania użytkownikami (CRUD) z walidacją `express-validator`.
* **Zadanie 4.5:** Modularyzacja aplikacji (podział na routing, kontrolery, serwisy) oraz asynchroniczna praca z plikami. Centralna obsługa błędów.
